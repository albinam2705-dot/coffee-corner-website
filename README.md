# Кав'ярня Coffee Corner
 
## Опис проекту
Це веб-сайт для кав'ярні Coffee Corner. Ми розробляємо зручну сторінку, де відвідувачі можуть переглядати меню, переглядати поточні акції, знаходити години роботи та контактну інформацію, а також заздалегідь розпочати свій візит.

## Проблема, мета та цільова група
- **Проблема:** Наразі клієнтам важко знайти інформацію про кав'ярню; їм доводиться шукати години роботи, запитувати через соціальні мережі, які напої доступні, або шукати місцезнаходження на карті.

- **Мета:** Створити простий, інтуїтивно зрозумілий та легкий веб-сайт, де відвідувачі можуть знайти всю необхідну інформацію про Coffee Corner за лічені секунди.

- **Цільова група:**

- Любителі високоякісної кави, десертів та випічки.

- Люди, які шукають затишне місце для роботи або зустрічі з друзями.

- Місцеві жителі та гості району, які хочуть швидко випити кави «на винос». ## Ролі користувача
- **Гість (Відвідувач):** Може переглядати головну сторінку, меню з цінами, годинами роботи, контактною інформацією та розташуванням на карті.

- **Адміністратор / Менеджер:** Може оновлювати меню та коригувати ціни та години роботи.

## Основні функції та сторінки
- **Головна сторінка:** Короткий опис кав'ярні, фотографії з атмосферою та актуальні новини чи акції.

- **Меню:** Огляд кави, чаю, сезонних пропозицій та десертів, включаючи ціни. - **Контактна інформація та розташування:** Адреса, карта, години роботи, номер телефону та посилання на соціальні мережі.
