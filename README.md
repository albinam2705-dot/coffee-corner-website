# Coffee Corner

## Project Description

Coffee Corner is a simple website for a coffee shop. Visitors can learn about the café, view the menu, and find contact information.

## Problem

Customers need a simple way to find information about a coffee shop, its drinks, food, and opening hours.

## Goal

The goal is to create a user-friendly website where customers can easily find information about Coffee Corner.

## Target Audience

- People who enjoy coffee and pastries.
- New customers looking for a café.
- Regular customers who want to check the menu and contact information.

## User Roles

- **Guest:** Can view the home page, menu, and contact information.
- **Registered User:** Can leave feedback and manage their profile.
- **Moderator:** Can review and manage customer feedback.
- **Administrator:** Can manage website content, users, and user roles.

## Main Features

- View the home page.
- Browse the coffee and food menu.
- View café information and opening hours.
- Send feedback.
- Manage customer feedback.
- Manage website content and user roles.

## Main Pages

- Home Page
- Menu Page
- About Us Page
- Contact Page
- Login and Registration Page
- User Profile
- Moderator Panel
- Administrator Panel
